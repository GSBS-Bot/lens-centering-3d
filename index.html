v1.0 2026-09-11
1.0 网站功能
  • 数据管理器 LDM：面表直接编辑（球面 / 圆锥 / 偶次非球面），插入删除、设光阑、撤销重做，导入 .zmx / .seq。
  • 实光线追迹内核：3D 旋转对称追迹 + 斯涅尔矢量折射；2026 玻璃库 Sellmeier 精确色散（1258 种牌号）。
  • 一阶量与渐晕：EFL / BFL / F#、入瞳直径与位置、逐面渐晕统计、按净口径自动渐晕。
  • 视场 / 波长：半视场角° 或像高 mm、多视场；波长权重编辑器（F/d/C 预设、自定义、主波长）。
  • 2D 光路剖面：镜片轮廓 + 光轴 + 光阑/像面标注，可平移缩放，主光线像高核对。
  • 3D 可视化：镜片实体 + 3D 光线，等轴测 / X-Y / Y-Z / X-Z 视图。
  • 点列图：Zemax 样式、按波长分色、艾里斑参考、RMS / GEO 半径。
  • 相对照度：一维曲线 + cos⁴θ 参考 + 设计视场标记。
  • MTF：几何 / 波前（衍射 FFT）两种算法，子午 T / 弧矢 S，支持复色（全波长加权）。
  • 多端适配：桌面 / 平板 / 手机响应式布局。
