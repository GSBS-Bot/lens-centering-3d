目录结构
--------------------------------------------------------------------
  3d可视化镜头调芯模型/
    ├─ 镜头调芯3D可视化网站开发计划.txt   开发计划与成本预估
    ├─ serve.bat / serve.ps1              一键起本地静态服务(python)
    ├─ reference/                         参考站(lens-bench)本地镜像
    └─ lens-3d/                           本项目(M1 数据管理器)
         ├─ index.html                    页面布局(左 LDM + 右 3D)
         ├─ css/style.css                 深色主题样式
         ├─ js/
         │    ├─ model.js                 数据模型 Surface/System + 示例镜头
         │    ├─ geom.js                  矢高/非球面 + 镜片回转体(3D)生成
         │    ├─ ldm.js                   LDM 面表格(编辑/插入/删除/光阑/撤重)
         │    ├─ import.js                .zmx / .seq 导入器
         │    └─ main.js                  接线: 模型->表格+3D 双向同步
         └─ vendor/three/                 three.js r180 本地依赖(无需联网)
              ├─ three.module.js  ├─ three.core.js  └─ OrbitControls.js

如何运行
--------------------------------------------------------------------
  方式一(推荐): 双击 serve.bat, 然后浏览器打开
      http://localhost:8000/lens-3d/       -> 本项目(LDM + 3D)
      http://localhost:8000/reference/     -> 参考站本地镜像
  方式二: 命令行 python -m http.server 8000 --directory <本目录>

  注意: 本项目用 ES Module, 必须经 HTTP 访问, 不能直接双击 index.html(file://)。
  开发期推荐用 serve_nocache.py(no-store), 改文件后普通刷新即生效:
      python serve_nocache.py 8000
